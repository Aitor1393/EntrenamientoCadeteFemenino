## Antes de tocar nada

1. **`git init` y un commit inicial.** Hay muchas versiones detrás de estos ficheros.
2. **El Excel se regenera, no se edita.** `python herramientas/build_seguimiento.py`
3. **Los códigos de familia cambiaron de significado** en septiembre de 2026. Cualquier documento
   anterior usa la numeración vieja: F8 era la zona y ahora es el rebote.
4. **Las fuentes no se transcriben.** Son obras con derechos; se referencian por número y página.
